## Conventions these issue write-ups must honour

Defer to the repo's CLAUDE.md and the approved design plan it names for the binding rules —
toolchain, output discipline, the require manifest, the commit-grouping traps. This hole is
where a project pins the *issue* conventions the shipped scaffold cannot know: the house
section order, how many scenarios an issue needs before it counts as specified, whether an
issue file names a role or an estimate, and who reviews the issue_plan gate. Override it at
`.lain/slots/skill/create-epic-issues/conventions.md`.
