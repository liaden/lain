# T1 — Give the cockpit's scratch buffer no swapfile

## Round 2 (REQUEST-CHANGES response)

The panel's real-nvim probe (`tmp/probe-T1-swapfile/probe-t1-matrix.sh` and
`probe-t1-decisive.sh`) showed round 1's fix (`-c SCRATCH_BUFFER -c NO_SWAPFILE -c LAIN_START`,
flag *after* the buffer open) does not fix the bug: `:file` creates the swapfile immediately,
so a peer's stale/dirty swap is already collided-with by the time `setlocal noswapfile` would
run, and nvim sits on "Press ENTER" before serving RPC. Addressed:

1. **Reordered the argv.** `nvim_pane_command` now emits
   `-c NO_SWAPFILE -c SCRATCH_BUFFER -c LAIN_START` — the swapfile guard runs *before* the
   buffer is ever opened. `'swapfile'` is buffer-local (not tied to the buffer's *name*), so
   `:file`'s in-place rename does not reset it; `setlocal noswapfile` issued first survives the
   rename. Verified directly with the panel's `probe-t1-decisive.sh`, run fresh against a
   manufactured stale `lain-cockpit:%%start.swp`: `ALT-setlocal-first` (my fix's exact argv
   shape) serves RPC within 4s despite the stale swap, and a normal file opened afterward in
   that same nvim still gets `&l:swapfile=1`/`&g:swapfile=1` — i.e. the scoping holds, unlike
   `ALT-cmd-global-n` (the forbidden `--cmd "set noswapfile"` form) which left both flags `0`
   for the normal file too.
2. **Fixed the terminology** in the `NO_SWAPFILE` comment: `'swapfile'` is now described as
   local to buffer per `:h 'swapfile'`, not "global-local"; `-n` is now called a startup flag
   that resets the global default, not an "option".
3. **Fixed the trigger description**: was "a busy swapfile", now says E325 fires on a *dirty*
   swapfile, and that the cockpit's scratch buffer is dirty as soon as a view lands (its
   steady state) — not a concurrency-window framing.
4. **Fixed the spec.** The full-argv `eq` (was `:1446-1449`) now expects
   `NO_SWAPFILE` before `SCRATCH_BUFFER`. Replaced the three unfalsifiable assertions
   (`NO_SWAPFILE == "setlocal noswapfile"` restating its own definition;
   `not_to include("-n")`/`not_to include("set")`, both structurally unreachable from an
   array-built, `Shellwords`-joined argv) with the one property that actually decides the
   card: `tokens.index(NO_SWAPFILE) < tokens.index(SCRATCH_BUFFER)`. Red-before-green run
   specifically on that assertion, isolated from everything else (see below).
5. **Dropped the line-number citation.** `annotate_spec.rb:88` (both in `cockpit.rb` and in
   `up_spec.rb`) is now cited by file and behaviour — "the neighbouring `annotate_spec.rb`'s
   editor `around` block" — per the CLAUDE.md rule against citing by line number.
